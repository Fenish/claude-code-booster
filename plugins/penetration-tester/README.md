# penetration-tester

Part of [cc-booster](https://github.com/Fenish/claude-code-booster) by fenish.

_This skill is curated from an external source. Original:
[mcpmarket.com](https://mcpmarket.com/tools/skills/security-penetration-tester)_

Automated penetration testing for web applications. Identifies OWASP Top 10
vulnerabilities and suggests remediation.

## Usage

Just ask naturally:

- "Run a penetration test on example.com"
- "Perform vulnerability assessment on the /api/users endpoint"
- "Assess the security posture of this web app"

## What It Does

1. Identifies the target web application or API endpoint
2. Scans for OWASP Top 10 vulnerabilities (SQLi, XSS, CSRF, etc.)
3. Generates a report with risk ratings and remediation steps

## Important

- Always have explicit authorization before testing any system
- Define the scope clearly to avoid unintended consequences
- Use exploitation techniques carefully to demonstrate flaws without causing
  damage
